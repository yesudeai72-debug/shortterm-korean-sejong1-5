# 세종한국어 1 · 5과 물건 사기 2 단원 평가

『세종한국어 1 익힘책』 5과 물건 사기 2 (66~69쪽, 72~76쪽 · 70쪽 듣기와 71쪽 말하기는 제외)을 웹 시험지로 만든 것입니다.
학생이 브라우저에서 문제를 풀고 **제출하면 자동으로 채점**됩니다.
자동 채점 문항은 61개이고, 점수는 100점 만점으로 바꿔서 보여 줍니다. 자유 쓰기와 자기 평가는 채점하지 않습니다.

## 파일 구성

```
index.html     시험지 화면
questions.js   문제와 정답  ← 문제를 고칠 때는 이 파일만 고치면 됩니다
app.js         화면 만들기와 채점
style.css      디자인 (화면, 모바일, 인쇄)
README.md      이 설명서
```

빌드 과정이 없습니다. `index.html`을 더블클릭해도 열립니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다. (예: `sejong1-lesson5`)
2. **Add file → Upload files**에 위 파일 5개를 끌어다 놓고 **Commit changes**를 누릅니다.
3. **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main`, 폴더를 `/ (root)`로 정하고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<내 아이디>.github.io/sejong1-lesson5/` 주소로 열립니다. 이 주소를 학생들에게 보내면 됩니다.

## 문제 고치기

`questions.js`에서 바꿀 수 있습니다.

- 빈칸 문항의 정답이 여러 개면 `answers`에 모두 넣으세요. 예: `answers: ["빵하고 우유", "우유하고 빵"]`
- 채점할 때 띄어쓰기, 마침표, 앞의 “네,”/“아니요,”는 무시합니다.
- 사지선다와 그림 고르기의 `answer`는 **0부터** 셉니다. (①=0, ②=1, ③=2, ④=3)
- 그림은 이모지, `{ scene: [...] }`(가구·동전·지폐 같은 간단한 그림에 이모지를 올린 장면) 또는 `flag:kr`, `flag:vn`, `flag:tw`, `flag:us`(국기)를 쓸 수 있습니다.

| type | 설명 |
|---|---|
| `match` | 그림 보고 단어 고르기 (드롭다운) |
| `picword` | 그림 보고 단어 고르기 (버튼) |
| `wordpic` | 단어 보고 그림 고르기 |
| `fill` | 빈칸 쓰기 |
| `dialog` | 대화·문장 속 빈칸 여러 개 |
| `pick` | 괄호 안에서 고르기 |
| `ox` | O / X |
| `choice` | 사지선다 |
| `free` | 자유 쓰기 (채점 안 함) |
| `self` | 자기 평가 (채점 안 함) |

## 참고

- 점수는 학생 화면에만 보이고 어디에도 저장되지 않습니다.
- 정답이 `questions.js`에 들어 있어서, 웹 개발을 아는 학생은 볼 수도 있습니다. 연습용으로 쓰기에 알맞습니다.
- 원본 교재의 그림은 넣지 않았고, 이모지와 간단한 그림으로 바꿨습니다.
- 정답은 익힘책 뒤의 「정답」을 따랐습니다.
- 문항 출처: 세종학당재단, 『세종한국어 1 익힘책』
